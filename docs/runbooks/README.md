# Tadka — Student runbooks

Copy-paste guides to run and verify **this branch's** code. Each day ships only the runbook for that day.

| Day | What you run | Runbook |
|-----|----------------|---------|
| 1 | Scaffold + liveness `/health`; Copilot adds `/health/ready`; Postgres down/up | [day-01.md](day-01.md) |

Later days add their own file here when that day's code exists. Do not look for Redis, Kafka, or extra services on Day 1 — they are not in this tree yet.

**Windows:** use `curl.exe`, not `curl`. Full ports and compose names are at the top of [day-01.md](day-01.md).
